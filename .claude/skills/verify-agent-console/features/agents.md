# Агенты

Агент — версионируемая конфигурация: название, модель, системный промпт, инструменты, навыки, MCP-серверы и вызываемые агенты.
Пользователь создаёт агента из шаблона в форме или в режиме YAML/JSON, видит его карточку со свойствами и историей версий, правит и архивирует.
Окружения у агента нет: окружение выбирается при создании сессии.

## Sub-features

- `agent-template` — первый шаг окна «Новый агент»: поиск «Поиск шаблонов» и карточки шаблонов («Пустой агент», «Глубокий исследователь» и другие).
- `agent-form` — вкладки «Основное», «Инструменты», «Навыки», «MCP-серверы», «Мультиагентность».
- `agent-code` — режимы «YAML» и «JSON» в группе «Режим правки». Без карточек моделей это единственный способ задать модель в окне.
- `agent-model-card` — выбор модели в группе «Модель». Работает, только если есть карточки на странице «Карточки моделей».
- `agent-tools` — «Включить инструменты», «Разрешение по умолчанию», режим для каждого инструмента (bash, edit, read, write, glob, grep, web_fetch, web_search, browser).
- `agent-detail` — `/agents/:id`: h1, регион «Свойства агента» (ID, Модель, Версия, Инструменты), «Системный промпт», «История версий».
- `agent-edit` — «Изменить», затем сохранение. Версия растёт.
- `agent-archive` — «В архив».

## How to get to it (user POV)

- Боковое меню, ссылка «Агенты» (`g` `a`), маршрут `/agents`. Кнопка «Новый агент» в панели или в пустом состоянии.
- Клик по строке списка открывает `/agents/:id`. После «Создать агента» консоль сама переходит на карточку.
- Ссылка «Добавить карточку» в предупреждении «Карточки моделей не настроены…» ведёт на `/model-cards`.

## Driving it with Playwright (verify-agent-console)

Preconditions:

- Учётка вошла в консоль. Режим модели `fake` или `real` (см. `features/README.md`).
- Карточек моделей нет. Это базовое состояние прогона, поэтому модель задаётся через YAML.

- **Открыть окно.** Нажать ссылку «Агенты» и дождаться h1 «Агенты» в `main` и пустого состояния «Агентов пока нет» (`agent.list_empty`; технический агент пробы к этому моменту в архиве), затем `getByRole("button", { name: "Новый агент" }).first()`. Результат: `getByRole("dialog", { name: "Новый агент" })` с подзаголовком «Выберите шаблон или соберите агента с нуля.».
- **Выбрать шаблон.** Нажать `dialog.getByRole("button", { name: /^Пустой агент/ })`. Результат: форма с полем `#agent-name`, в нём «Пустой агент». В `#agent-system` стоит промпт шаблона.
- **Заполнить форму.** Заполнить `#agent-name` значением `verify-agent-<nonce>` и `#agent-system`. Результат: видно предупреждение «Карточки моделей не настроены…», группы «Модель» нет. Это строка «внимание» `agent.form_without_model_cards`: в режиме «Форма» агента без модели не создать.
- **Инструменты.** Открыть `dialog.getByRole("tab", { name: /^Инструменты/ })`. Результат: включён флажок «Включить инструменты», разрешение по умолчанию «Всегда разрешать» (`INITIAL_FORM` в `pages/agents/agentFormCodec.ts`).
- **Задать модель через YAML.** Нажать `dialog.getByRole("group", { name: "Режим правки" }).getByRole("button", { name: "YAML", exact: true })`. В `getByRole("textbox", { name: "Конфигурация агента в формате YAML" })` заменить строку `model:` на `model: claude-sonnet-4-6`. Результат: текст YAML содержит name, model, system и tools.
- **Создать.** Нажать `getByRole("button", { name: "Создать агента", exact: true })`. Результат: URL `/agents/<id>`, h1 с названием, `getByRole("region", { name: "Свойства агента" })` содержит `claude-sonnet-4-6`. Ошибка показывается блоком `[role=alert]` внутри окна.
- **Сверить запись.** Вызвать `GET /v1/agents/:id`. Результат: `name`, `model` (строка или `{id}`), `system`, в `tools` есть `agent_toolset_20260401`, bash не отключён. Ключа `environment` нет.
- **Модель через карточку (`agent-model-card`).** Открыть «Карточки моделей» и создать карточку. Поля формы (`pages/ModelCardsList.tsx:436-543`):
  - `#modelcard-id` — `verify-fake`;
  - «Провайдер Pi *» — anthropic (`ant`);
  - `#modelcard-api-key` — тестовое значение `local-fake`, только в режиме fake;
  - `#modelcard-wire-model` — `claude-sonnet-4-6`;
  - `#modelcard-base-url` — `http://127.0.0.1:8792`, без `/v1`.

  Затем открыть «Новый агент». Результат: в форме появилась группа «Модель» с выбранной карточкой. Агент с `model: verify-fake` ходит в фейковую модель через карточку (`apps/main-node/src/modules/node-foundation.ts:291-342`). Скрипта для этого пути нет, порядок полей и выбор провайдера по интерфейсу не проверялись.
- **Правка.** На карточке нажать «Изменить», поменять системный промпт, сохранить. Результат: «Версия» `v2`, в «Истории версий» две записи, у текущей бейдж «Текущая».
- **Доказательство.** `screens/*agent-*.png`, `aria/*agent-detail.yml`, `api/30-agent-create.yaml`, `api/31-agent.json`, строки `agent.*` в `summary.md`.

## Gotchas

- Без карточек моделей форма отправляет `model: ""`, потому что у шаблонов `model: ""` (`data/templates.ts`). Через режим «Форма» агента без модели не создать. Не обходите это прямым API-вызовом: используйте YAML или карточку.
- Нужна ли карточка, зависит от маршрута. `/v1/agents` (его зовёт консоль) не сверяет модель с карточками. `/v1/oma/agents` требует, чтобы `model_id` совпадал с активной карточкой, если хоть одна карточка есть (`modules/node-http.ts:345-358`).
- Если карточка с `model_id`, равным `agent.model`, есть и у неё есть ключ, сервер берёт ключ и URL из карточки, а не из `ANTHROPIC_*`. Лишняя карточка может увести фейковый прогон на настоящий API.
- При переключении «Форма» → «YAML» форма сериализуется. Обратное переключение разбирает YAML, и ошибка разбора остаётся в `[role=alert]`.
- Имя кнопки шаблона включает описание и теги. Ищите регуляркой `^Пустой агент`, а не точным именем.
- У строк таблицы агентов нет `title`, и у `section` нет подписи. Ищите строку по тексту имени.
- Список агентов в окне «Новая сессия» включает архивных агентов (`include_archived: true`). Выбирайте агента по id.
- Список «Агенты» по умолчанию показывает только активных (фильтр «Статус: Активные», `include_archived` не передаётся, `pages/AgentsList.tsx:57-60`). Поэтому технический агент пробы окружения после архива не мешает пройти путь по пустому списку.
- Подфункции `agent-model-card`, `agent-edit`, `agent-archive` главный сценарий не проходит; в `summary.md` они идут строками «не проверено» `feature.*`.
