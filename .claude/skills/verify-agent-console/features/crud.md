# Правка, архив и удаление

Каждую сущность можно изменить, отправить в архив, вернуть из архива и удалить. Архив и удаление проверяют зависимости: блокирующая зависимость даёт окно со списком «Мешает» и ответ 409 `dependency_conflict_error`. Помощник делает архив и удаление только после клика по красной карточке.
Проект: `docs/plans/crud.md`, сверка пробелов `.audit/crud-gaps.md`. Подфункции этого файла считает сценарий `crud` (`scripts/journey-crud.mjs`), главный сценарий их не считает.

## Sub-features

- `crud-agent-archive`: «Агенты», меню строки «В архив», окно «Отправить агента в архив?» со строкой «Можно вернуть из архива»; фильтр «Статус: В архиве», пункт «Вернуть из архива».
- `crud-env-archive`: то же для «Окружений», окно «Отправить окружение в архив?».
- `crud-env-delete`: окружение с живой сессией: окно удаления со списком «Мешает» и выключенной кнопкой «Удалить», DELETE отвечает 409 со списком; после архива сессии в «Сессиях» окно без «Мешает», окружение удалено, его архивная сессия удаляется из «Сессий».
- `crud-deployments`: «Создать деплоймент» в меню агента, форма `/deployments/new?agent=<id>`, деплоймент на паузе, «Запустить» выключена на паузе, «Продолжить», «Запустить» с прогоном на вкладке «Прогоны», «Пауза», «В архив».
- `crud-files`: «Файлы», кнопка «Загрузить», строка с именем, меню строки «Удалить», окно «Удалить файл …?» со строкой «Это нельзя отменить».
- `crud-assistant-danger`: помощник читает `get_dependencies`, затем красная карточка «Архивировать сессию …» (метка «Опасное», кнопка «В архив»), затем «Удалить файл …» («Это нельзя отменить», кнопка «Удалить»). До клика объекты на месте, прямой `user.tool_confirmation` без карточки даёт 403.
- `crud-assistant-deny`: карточка удаления файла висит без клика, файл на месте; «Отклонить» оставляет файл, результат `is_error`, строка журнала `denied`.

## How to get to it (user POV)

- Списки «Агенты», «Окружения», «Сессии», «Файлы»: правая кнопка мыши по строке открывает меню действий («В архив», «Вернуть из архива», «Удалить», у агента «Создать деплоймент»).
- Чип «Статус» над списком: «Активные», «В архиве», «Все». Архивная строка видна только с фильтром «В архиве» или «Все».
- «Деплойменты» в меню слева; карточка `/deployments/:id` с кнопками «Запустить», «Пауза» или «Продолжить», «Изменить», «В архив», у архивного «Вернуть из архива».
- Помощник: Ctrl I, реплика с просьбой архивировать или удалить объект.

## Driving it with Playwright (verify-agent-console)

- Меню строки: `tr[data-slot="table-row"]` с текстом имени, `click({ button: "right" })`, затем `getByRole("menuitem", { name, exact: true })`.
- Окно архива и удаления это `getByRole("dialog", { name: <заголовок> })`. Пока в окне текст «Проверяем, что связано с объектом…», кнопка выключена. Ждите, пока текст уйдёт, и только потом читайте кнопку.
- Списки зависимостей это `region` «Мешает» и «Затронет» (`DependencyList`).
- Фильтр статуса: кнопка с текстом, который начинается с «Статус», затем `option` «В архиве».
- Форма деплоймента: `#deployment-name`, два `combobox` в `main` (агент из `?agent=` уже выбран, окружение выбирается пунктом `[data-slot="command-item"]` с id), `#deployment-message`, «Создать» в шапке.
- Загрузка файла: `page.waitForEvent("filechooser")` до клика «Загрузить», затем `setFiles({ name, mimeType, buffer })`.
- Карточка помощника: `article.assistant-card[data-tool="archive_object"][data-phase="pending"]`, у опасной `data-danger="true"`.

## Gotchas

- Список по умолчанию показывает только активные объекты: после «В архив» строка пропадает, это ожидаемо.
- Живая сессия это сессия не в архиве со статусом `idle`, `running` или `rescheduling`. Новая сессия без сообщения `idle`, поэтому она блокирует удаление окружения.
- Сервер запускает только активный деплоймент: у деплоймента на паузе `POST /run` отвечает 409 «is not active».
- Помощник не трогает свои объекты: архив своей сессии или своего агента уходит в класс «вне v1». Поэтому сценарий архивирует обычную сессию, созданную по API.
- Решения фейка: маркер `VERIFY_BUILDER_CRUD nonce=<n>` со строками `Сессия:` и `Файл:` и `VERIFY_BUILDER_CRUDDENY nonce=<n>` со строкой `Файл:` (`fake-model-builder.mjs`).
