# Навыки

Навык — папка с `SKILL.md` в формате Anthropic, которую пользователь загружает архивом `.zip`.
Встроенные навыки («Excel (xlsx)», «PDF», «PowerPoint (pptx)», «Word (docx)») и пользовательские подключаются к агенту на вкладке «Навыки».
Во время сессии файлы навыка оказываются в песочнице агента.

## Sub-features

- `skill-list` — список «Навыки», фильтр «Источник»: «Встроенные» или «Пользовательские».
- `skill-upload` — окно «Загрузка пользовательского навыка»: архив, отображаемое название, «Загрузить».
- `skill-detail` — окно деталей навыка с версиями. Отдельного маршрута у него нет.
- `skill-attach` — вкладка «Навыки» в форме агента: флажок навыка и поле «Версия навыка {id}».
- `skill-in-sandbox` — файлы навыка внутри VM в `/workspace/.openma/skills/<skill_id>/<версия>/…`.

## How to get to it (user POV)

- Боковое меню, ссылка «Навыки» (`g` `k`), маршрут `/skills`, кнопка «Новый навык».
- Форма агента: «Новый агент» или «Изменить», вкладка «Навыки». Ссылка «Создать навык» видна, если своих навыков нет.

## Driving it with Playwright (verify-agent-console)

Preconditions:

- Учётка вошла в консоль, своих навыков нет.
- Подготовлен архив `verify-skill-<nonce>.zip` с одним файлом `verify-skill-<nonce>/SKILL.md`. В frontmatter файла `name: verify-skill-<nonce>` и `description: …`, в теле маркер `VERIFY_SKILL_<nonce>`. Такая же структура пути `<dir>/SKILL.md` используется в `platform/scripts/ddc-shots.mjs:123-125`.
- Скрипта для этой функции пока нет. Шаги выполняются кодом Playwright по образцу `scripts/journey-env-to-agent.mjs` (вход, `shot`, `api`, `check`).

- **Открыть загрузку.** Нажать ссылку «Навыки», затем `getByRole("button", { name: "Новый навык" })`. Результат: `getByRole("dialog", { name: "Загрузка пользовательского навыка" })`.
- **Выбрать архив.** Вызвать `getByLabel("Архив навыка (.zip)").setInputFiles(<zip>)`, затем заполнить поле «Отображаемое название (необязательно)». Результат: имя файла видно в окне, кнопка «Загрузить» активна.
- **Загрузить.** Нажать `getByRole("button", { name: "Загрузить" })`. Результат: окно закрылось, в таблице «Навыки» есть строка с чипом «Пользовательский». `GET /v1/skills` с beta `skills-2025-10-02` содержит навык, `GET /v1/skills/:id/versions` — одну версию.
- **Подключить к агенту.** В окне агента открыть вкладку `getByRole("tab", { name: /^Навыки/ })` и отметить флажок с подписью названия навыка. Результат: счётчик на вкладке равен 1. После сохранения `GET /v1/agents/:id` возвращает `skills` с `type: "custom"` и `skill_id`.
- **Навык в песочнице.** Создать сессию с этим агентом. Промпт (режим fake): `Команда: find /workspace/.openma/skills -name SKILL.md -exec grep -l VERIFY_SKILL_<n> {} + && echo VERIFY_OK_<n>` и строка `VERIFY_AGENT_RUN nonce=<n>`. Результат: `agent.tool_result` содержит путь к `SKILL.md` и `VERIFY_OK_<n>`.
- **Доказательство.** Скриншоты окна загрузки, строки списка и вкладки «Навыки», `api/skills.json`, `api/agent-with-skill.json`, журнал событий сессии.

## Gotchas

- Консоль сама распаковывает zip и отправляет файлы (`lib/skill-upload.ts`). Пустой архив даёт ошибку «В архиве навыка нет файлов», файл не `.zip` — «… не является архивом .zip».
- Точный путь внутри `/workspace/.openma/skills/<id>/<версия>/` (есть ли там папка `<dir>/`) по запуску не проверялся. Ищите файл через `find`, а не по жёсткому пути.
- Навыки монтируются при подготовке песочницы. Отпечаток песочницы включает `skills`, поэтому смена навыков агента пересоздаёт VM на следующем ходе (`apps/main-node/src/lib/node-managed-session-runner.ts:231-268`).
- Кнопка «Установить по ссылке» есть только при `skillSources.available`. На этом стенде источники не настроены.
- Маршруты `/v1/skills*` требуют beta `skills-2025-10-02`. Флаг `managed-agents-2026-04-01` для них не подходит (`packages/managed-agents-api/src/beta.ts:12-29`).
