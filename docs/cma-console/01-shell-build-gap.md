## 5. Расхождения с DDC и решения для владельца

1. Инспектор не модальный и без затемнения. Правило 11 DDC: любое окно только `Modal`. Нужно либо дописать компонент «Инспектор» в [ddc-design-system.md](../ddc-design-system.md), либо открывать карточки через `Modal`. Для «Один в один» нужен первый вариант.
2. Колонка иконок. В портале DDC свёрнутое меню 64 px, у Claude 48 px. Предлагаю взять размер портала (64 px) и поведение Claude (карточка группы по клику).
3. Меню на телефоне. Оставляем ящик 288 px с затемнением (правило 13 DDC). Поведение Claude (меню толкает страницу до 130 px) не повторяем.
4. Верхняя панель с хлебными крошками. У Claude её нет. Убрать её значит менять оболочку всех страниц, в планах этого нет. Оставляю как отличие, нужен ответ владельца.
5. Высоты контролов. У Claude кнопки и чипы 32 px, у DDC ряд страницы 40 px и панель инструментов 36 px (правило 1). Берём высоты DDC.
6. Цветные плитки моделей. Правило 5 DDC запрещает градиенты. Шапка плитки делается плоским цветом из токенов рядов графиков.
7. Ширина Dashboard. У Claude колонка 944 px по центру, у DDC плотные данные идут на всю ширину. Берём DDC.
8. Заголовки таблицы. DDC требует заглавные `th` с разрядкой, у Claude заголовок 13 px обычным регистром. Берём DDC.

5. Два плана называют лимиты карточек по-разному. [analytics.md](../plans/analytics.md) и уже лежащий код `N/lib/analytics/limits-store.ts` используют таблицу `model_card_limits` по `card_id` и маршрут `PUT /limits/:card_id`. [console-parity.md](../plans/console-parity.md) (S5, K13) описывает `model_limits` по handle и `PUT /model_limits/:handle`. Выбрать одно до старта K13.
