# 01. Меню, обзор, ключи и «Сборка» (Claude Console, консоль Managed Agents / API)

Источник: platform.claude.com, личная учётная запись владельца, режим «только чтение».
Дата обхода: 2026-10-16. Рабочее пространство в URL: `default` (дальше `<ws>`). Идентификаторы
учётной записи, ключей, навыков и версий заменены на `<id>`; почты, имена, суммы, баланс не
записаны (пишу «участник», «сумма», «ключ»).
Размеры сняты на десктопном окне 1586 x 1280 (DPR 1) и на узком 390 x 844. «Подпись» ниже это короткий
оригинал в обратных кавычках и рядом русский смысл.

Скриншоты лежат в `.audit/cma-screens/01-shell-build/` (папка в .gitignore).

## Общая оболочка и токены (для всех панелей раздела)

- Шрифты: интерфейс `anthropicSans`, логотип и приветствие на Dashboard `anthropicSerif`, значки это
  глифы шрифта `Anthropicons-Variable` (20 px в меню, 16 px в таблицах, 24 px в кнопках-иконках),
  идентификаторы и ключи моноширинным.
- Цвета: фон страницы `#fcfcfb`, фон меню `#f9f9f7`, текст `#0b0b0b`, вторичный `#52514e`,
  приглушённый `#898781`, тонкая линия и заливка активного пункта `rgba(11,11,11,.10)`.
  Главная кнопка чёрная `#0b0b0b` с белым текстом, вторичная прозрачная с тонкой рамкой.
- Типографика: заголовок страницы 22 px / 500, подзаголовок секций 15-16 px / 580, основной текст 14 px,
  шапка таблицы 13 px / 500 без верхнего регистра, подписи и вторичные строки 13 px, у кнопок высота 32 px
  и радиус 8 px, у карточек радиус 12 px, внутренний отступ 16 px.
- Каркас: слева меню 256 px, справа область страницы без верхней панели; шапка страницы лежит
  внутри области (заголовок на y=24, отступ слева 24 px от меню). Страницы-таблицы занимают всю ширину
  (x от 268 до 1574 при окне 1586, поля по 12 px), Dashboard держит центральную колонку 944 px.
- Боковые панели деталей (инспекторы) и ящики плавают поверх страницы карточкой с отступом 8-12 px от
  краёв окна, без затемнения фона; Escape закрывает; модальные диалоги с затемнением по центру.

## 1. Левое меню, развёрнутое

Путь: везде. Назначение: навигация по разделам консоли и переключение рабочего пространства.

```
+------------------------------+  x=0..256, высота = окно
| Claude Console        [ |< ]  |  логотип (serif) слева; кнопка сворачивания 28x28 справа (x=216)
| [■ Default            v ]    |  переключатель пространства 224x32 (y=56)
| [🔍 Search Console… Ctrl K]  |  кнопка поиска 232x32 (y=96)
|                              |
| ⌂ Dashboard                  |  пункт 36 px (y=145), шаг 40 px
| 🔑 API keys                  |
| 🔨 Build                  v  |  заголовок группы 36 px, шеврон справа
|      Playground              |  вложенный пункт, отступ слева 40 px, без иконки
|      Files                   |
|      Skills                  |
|      Batches                 |
|   (зазор групп 8 px)         |
| ⚙ Managed Agents          v  |
|      Quickstart / Agents / Sessions / Deployments /
|      Environments / Credential vaults / Memory stores
| 📈 Analytics              v  |
|      Usage / Caching / Rate limits / Cost / Logs
| >_ Claude Code            v  |  (вне раздела: Usage, Settings)
| ▦ Manage                  v  |  (вне раздела: Rate limits, Spend limits, Service accounts,
|                              |   App integrations + плашка `Beta`, Data retention, OpenTelemetry, Webhooks)
|------------------------------|  липкий низ (тонкая линия сверху)
| 🔔 Notifications             |
| 📖 Documentation             |
| ◔ Credits          [баланс]  |  справа плашка с суммой (в загрузке серый скелетон)
| [▣] имя пользователя     >   |  кнопка аккаунта 232x49: плитка 32 px, имя 14 px, под ним организация 12 px
+------------------------------+
```

- Состав верхнего уровня: `Dashboard`, `API keys`, группа `Build` (`Playground`, `Files`, `Skills`, `Batches`),
  группа `Managed Agents` (`Quickstart`, `Agents`, `Sessions`, `Deployments`, `Environments`,
  `Credential vaults`, `Memory stores`), группа `Analytics` (`Usage`, `Caching`, `Rate limits`, `Cost`, `Logs`).
  Дополнительно в этом аккаунте есть группы `Claude Code` и `Manage` (в раздел не входят, перечислены для полноты).
- Иконки есть только у верхних пунктов и заголовков групп: дом (Dashboard), ключ (API keys), молоток (Build),
  схема агентов (Managed Agents), график (Analytics), терминал (Claude Code), кубики (Manage).
  У вложенных пунктов иконок нет, текст выровнен на 40 px.
- Пункт: высота 36, горизонтальный отступ 8, расстояние иконка-текст 12, радиус около 4. Верхние пункты
  с весом 500, вложенные обычные. Цвет текста вторичный; активный пункт: заливка `rgba(11,11,11,.10)` и
  основной цвет текста (`aria-current="page"`); при наведении лёгкая заливка. Длинный текст обрезается
  многоточием, на обрезанных всплывает подсказка.
- Группы сворачиваются кликом по заголовку (`aria-expanded`), шеврон вниз у раскрытой и вправо у
  свёрнутой. Состояние группы не меняет остальные.
- При полном раскрытии список длиннее окна: прокручивается внутри меню под липким низом, нижние пункты
  частично скрыты низом.
- Низ: `Notifications` (колокол, ссылка), `Documentation` (книга, ссылка на документацию), `Credits`
  (кнопка со всплывающей карточкой, справа сумма), кнопка аккаунта (меню пользователя не открывалось).
- Край меню это ручка изменения размера (`role=separator`, подпись `Expand or collapse the sidebar`,
  полоса 12 px, курсор col-resize, два положения 0 и 1, фокусируется с клавиатуры).
- Загрузка: селектор рабочего пространства и сумма в `Credits` показывают серые плашки-скелетоны, затем
  подставляются значения.

## 2. Левое меню, свёрнутая колонка

Кнопка `Collapse` (28x28 вверху справа) сворачивает меню в колонку иконок шириной 48 px, `Expand`
(28x28 слева, x=8) возвращает.

- Колонка: плитка текущего пространства 32x32 (буква в цветной плитке, подпись `Default`), кнопка поиска
  32x32 (`Search`), затем иконки Dashboard, API keys, Build, Managed Agents, Analytics, Claude Code, Manage
  (по 36x36, шаг 40, x=6), внизу колокол, книга, `Credits`, круглый аватар 32 px (`User menu`).
- Все иконки имеют `aria-label`; активная иконка в закрашенном скруглённом квадрате.
- Заголовки групп без текста: клик по иконке группы открывает всплывающую карточку справа от колонки
  примерно 190-200 px шириной: серый заголовок группы (например `Build`) и ссылки 36 px (`Playground`,
  `Files`, `Skills`, `Batches`). Закрывается Escape или кликом вне.

## 3. Переключатель рабочего пространства

Всплывает под кнопкой (поповер 256x158, x=12, y=94). Кнопка: цветная плитка, имя `Default`, шеврон.

- Список: `All workspaces` (серая строка 45 px с пояснением, что на этой странице нет общего вида;
  недоступна), `Default` (цветная точка, отметка выбранного, строка 32 px).
- Под линией две кнопки 32 px: `Create workspace` (плюс) и `Manage workspaces`.
- На страницах уровня организации (например раздел Claude Code) кнопка недоступна и показывает серое
  `All workspaces`.

## 4. Поиск по консоли (Ctrl K)

Кнопка `Search Console…` с клавишами `Ctrl` `K` (или иконка поиска в колонке). Открывает модальную палитру команд
672x500 по центру сверху (x=457, y=192) с затемнением.

- Строка ввода: лупа, подсказка по смыслу «искать доки, страницы, рабочие пространства, агентов»
  (`Search docs, pages, workspaces, agents`), справа кнопка очистки.
- Секция `Pages`: все пункты меню в виде «группа › пункт» (`Build › Playground`, `Managed Agents › Sessions`,
  `Analytics › Cost` и так далее), плюс `Notifications`, `Documentation`, `Quickstart` и около 11 страниц
  настроек организации (`Organization settings › General, Organization, Workspaces, Billing, Rate limits,
  API keys, Service accounts, Workload identity, OpenTelemetry, Data retention, Capabilities, Identity and access`).
  Строка 36 px, у выбранной серая заливка и значок Enter справа; у текущей страницы стоит отметка.
- Секция `Popular docs`: три документа с путём в доках (`Get started with Claude`, `Models overview`,
  `Prompt caching`).
- Низ: подсказки клавиш `Select ↑ ↓` и `Open menu Ctrl K`.
- Закрывается Escape. Замечание: синтетическое нажатие Ctrl K в моём прогоне палитру не открыло (скорее всего
  не было фокуса в странице), открыл кликом по кнопке.

## 5. Левое меню на 390 px

- Меню само уходит в колонку иконок 48 px (страница при этом занимает остальные 342 px). При холодной
  загрузке первый кадр рисуется с развёрнутым меню 256 px и через несколько секунд меню сворачивается.
- Кнопка `Expand` раскрывает меню на 256 px, но не накладывает его поверх страницы и без затемнения:
  меню толкает содержимое, оно сжимается до 130 px. Это не выдвижной ящик.
- Вверху колонки: плитка рабочего пространства (буква), поиск, иконки разделов; внизу колокол, книга,
  `Credits`, аватар.

## 6. Dashboard

Путь `/dashboard`. Назначение: сводка по кредитам, расходу, кэшу промптов и объёму токенов плюс ссылки
на модели и ресурсы.

```
x=449..1393 (944 px, по центру области)
y=48   Good morning, <имя> (serif 22/500)       [📖] [🔑 Get API key] [■ Build an agent]
y=96   +----------------+ +----------------+ +----------------+   карточки 307x136, зазор 12, радиус 12, pad 16
       | Organization   | | Spend this     | | Prompt caching |
       | credits  (i)   | | month  [0% used]| |  [Not enabled]|
       | <сумма>        | | <сумма> ( ◯ )  | |  —            |
       | [Add funds]    | | из лимита · …  | | tokens reused  |
       | Turn on auto-  | |                | |   [Set up]     |
       | reload (ссылка)| |                | |                |
       +----------------+ +----------------+ +----------------+
y=244  +-----------------------------------------------------+   карточка 944x136
       | Token volume (i)                      ~ спарклайн 96x48 справа |
       | 0    last 7 days                                    |
       +-----------------------------------------------------+
y=405  Models (15/580)                              Compare models (ссылка справа)
y=437  4 плитки 227x90 в ряд, зазор 12: цветная шапка (синяя, оранжевая, кремовая, мятная) с линейной
       иллюстрацией; ниже название 14/580 и три плашки-признака
y=652  Resources (15/580)
y=688  4 карточки 227 px: значок, название, бейдж `Beta` у первой, описание 3-4 строки, кнопка внизу
y=1239 API status · Help and support · Feedback (13 px, приглушённые, по центру)
```

- Шапка: заголовок серифом с приветствием (на проверенных API keys и Batches заголовок обычным sans), справа кнопка-иконка 32x32
  (книга, ведёт в документацию), вторичная `Get API key` (значок ключа, 121x32, открывает диалог создания ключа,
  не нажимал) и главная чёрная `Build an agent` (138x32, ссылка на `/workspaces/<ws>/agent-quickstart`).
- Карточка `Organization credits`: заголовок-ссылка на биллинг, кнопка-иконка `More info about organization
  credits` (28x28), крупная сумма, `Add funds` (92x32), ссылка-предупреждение `Turn on auto-reload`.
- Карточка `Spend this month`: заголовок-ссылка на `/cost?range=mtd`, плашка `0% used`, крупная сумма, подпись
  «из лимита уровня · сброс в дату», кольцевая диаграмма 48x48 справа (пустое кольцо при нуле).
- Карточка `Prompt caching`: заголовок-ссылка на `/usage/cache?workspace=<ws>`, плашка `Not enabled`, прочерк и подпись
  `tokens reused`, вторичная кнопка `Set up` (ведёт в документацию).
- Карточка `Token volume`: заголовок-ссылка на `/usage`, число и подпись `last 7 days`, спарклайн справа.
- Плитки моделей: `Fable 5.1` (признаки `Most capable`, `Research`, `Multi-day tasks`), `Opus 5.5` (`Complex projects`,
  `Agents`, `Coding`), `Sonnet 5.5` (`Everyday tasks`, `Writing`, `Cost-efficient`), `Haiku 5.5` с бейджем `New`
  (`Fastest`, `Lowest cost`, `High volume`). Названия и вся плитка ведут в обзор моделей.
- Карточки ресурсов: `Advisor tool` (`Beta`, кнопка `Try in playground` и кнопка-иконка документации; ведёт в
  Playground с шаблоном), `Fast mode`, `Batch API`, `Prompt caching` (у трёх кнопка `Open docs`, 111x28).
- Состояния: загрузка (12 серых скелетонов в карточках, 2-3 секунды, плашки в меню тоже), загруженное,
  пустые значения показываются как `0` и `—`. Ошибка и нет доступа не воспроизводились.
- Поведение: заголовки карточек это ссылки на соответствующий отчёт; подсказки у кнопок `i` описаны как
  `More info about …` (при наведении подсказка в снимке не появилась).
- 390 px: всё в одну колонку на всю ширину (342 px минус поля 16), шапка в два ряда (заголовок, затем три кнопки
  в одну строку); карточки идут друг под другом, у `Spend this month` кольцо остаётся справа; плитки моделей
  становятся горизонтальными строками (значок слева, название и плашки справа); ресурсы друг под другом.

## 7. API keys, список

Путь `/settings/keys?ws=<ws>` (параметр `ws` задаёт фильтр по пространству). Назначение: ключи API
пользователя и сервисных аккаунтов.

```
y=24   API keys [1]                                                      [+ Create key]   (117x32, чёрная)
       строка-описание: ключ действует от лица владельца, ключ пространства живёт после ухода автора
y=100  [🔍 Search keys     ] [Created by: Anyone v] [Linked account: All v] [Status: All v] [Workspace: ■ Default ✕]   [↺ Reset]
y=156  Key ▲▼ | Linked account | Scope ▲▼ | Expires ▲▼ | Created ▲▼ | Cost ▲▼ |  (шапка 32 px)
y=188  имя / `sk-…` | аватар имя     | ■ Default (i) | дата | аватар имя дата | — | ⋮    (строка 58 px)
```

- Шапка: заголовок 22/500 и счётчик-плашка рядом (`1`), описание одной-двумя строками, справа главная кнопка
  `Create key` (значок плюс, открывает диалог, панель 10).
- Панель фильтров (y=100, высота 32): поиск `Search keys` (272 px, лупа), затем выпадающие
  чипы: `Created by` (по умолчанию `Anyone`, 162 px), `Linked account` (`All`, 156), `Status` (`All`, 98),
  `Workspace` (по умолчанию значение `Default` с цветной плиткой и кнопкой сброса `Clear selection` 22x22, 164),
  справа вторичная `Reset` (82x32, стрелка назад).
- Колонки по порядку: `Key` (263: имя, под ним маска ключа моноширинным, префикс, многоточие, хвост),
  `Linked account` (263: кружок-аватар 20 px с буквой, имя, под ним почта 13 px, метка `(you)` у своей),
  `Scope` (263: цветная плитка и имя пространства ссылкой в настройки пространства, кнопка-иконка 24x24
  `About the default workspace`), `Expires` (110: дата «мес д, год»), `Created` (263: аватар создателя, имя,
  дата 13 px приглушённая), `Cost` (90: сумма или `—`), `Actions` (56: кнопка «⋮» 28x28 `More actions for <имя>`).
- Сортировка: заголовки `Key`, `Scope`, `Expires`, `Created`, `Cost` это кнопки сортировки; `Linked account` и
  `Actions` не сортируются. Клик по сортировке не делал.
- Плотность: шапка 32 px, строка 58 px, ячейки 14 px, шапка 13 px; линия под шапкой тонкая, между строками
  линий нет; вся строка это одна кнопка (открывает инспектор), кроме ссылок и кнопок внутри.
- Пагинации в снимке нет (в списке одна запись).
