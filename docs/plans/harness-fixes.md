# Дефекты harness и инструментов агента

Разбор кода 2026-10-17. Пути от `platform/apps/agent/src/harness/`. Отметка «(проверено)» значит, что строку перечитал координатор. Без отметки находка взята из отчёта исследователя. Исправленный пункт переносится в раздел «Исправлено» с хэшем коммита.

## Открыто

### Бьёт по Qwen (PiHarness)

1. (проверено) `pi-loop.ts` `shouldRetryPiTurnAfterCompaction`: при `producedOutput` повтора нет. После первого вызова инструмента переполнение контекста роняет ход вместо сжатия.
2. (проверено) `pi-loop.ts:165`: слушатель `abort`, добавленный после отмены, не срабатывает. Отмена во время сжатия не останавливает ход.
3. (проверено) `pi-compaction.ts:187`: отклоняется только `stopReason === "error"`. Сводка, оборванная по `aborted` или `length`, становится границей сжатия.
4. `pi-loop-tools.ts:30`: `terminate` только у подтверждаемого вызова. В смешанном батче цикл Pi идёт дальше, и результат после подтверждения попадает в историю не на своё место. Нужен сквозной прогон.
5. `pi-loop.ts:405`: ответ из одних мыслей считается выводом, пустой `stop` вызывает сжатие. DefaultHarness в этом случае бросает `silent_stop`.
6. `pi-loop.ts:486`: у результата инструмента нет `parent_event_id`, у `call_agent_*` нет `thread_message_received`.
7. Нет лога тел запросов к LLM, как у `llmLoggingMiddleware` в default-loop.

### Инструменты (`tools.ts`)

8. `:690`, `:772`: glob и grep разбирают только формат Cloudflare `exit=N`. На LiteBox модель получает голое `[exit 1]`, длинный вывод не обрезается.
9. (проверено) `:665`: `content.replace(old, new)` со строкой разворачивает `$&` и `$$` в новом тексте.
10. (проверено) `:688`: `pattern` glob стоит в `bash -c` как код. Через glob можно выполнить команду в обход `always_ask` на bash (только внутри VM).
11. `:197`: `truncateResult` оставляет начало вывода, а код выхода LiteBox и ошибка сборки стоят в конце.
12. `:650-667`: параллельные `edit` одного файла затирают друг друга.

### ACP

13. `acp-sandbox-loop.ts:305`: при ошибке span закрывается как успешный, нет `promptError` перед `flush`.
14. `acp-proxy-loop.ts:154`: переподключение без лимита и без проверки отмены, ход может висеть вечно.
15. `acp-translate.ts:410`: результат инструмента ACP пишется в журнал целиком.

### DefaultHarness (устаревший)

16. (проверено) `default-loop.ts:465`: `maxTokens` в ai 7 называется `maxOutputTokens`, лимит агента игнорируется.
17. `default-loop.ts:851`: упавший инструмент попадает в `pendingConfirmations`.
