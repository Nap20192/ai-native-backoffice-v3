# Как ассистент строит агента

Изменения: процесс создания агента пересказан по навыку `create-agent` из OpenMA (Apache-2.0). Мы заменили команды `oma` на инструменты ассистента, имена моделей на карточки моделей и добавили подтверждение каждой записи. Источники в `THIRD_PARTY_NOTICES.md`.

## Процесс

1. Пойми цель. Спроси, что агент должен делать, если это неясно. Не больше двух раундов вопросов, потом строй и назови допущения.
2. Проверь, что уже есть. `list` с видами `agents`, `environments`, `skills`, `models`. `search_config` находит похожих агентов по тексту промпта.
3. Выбери модель из карточек. Для простых задач подходит быстрая карточка, для кода и долгих задач сильная. Если пользователь назвал модель, возьми её.
4. Напиши системный промпт. Правила в `system-prompts.md`.
5. Выбери инструменты. Встроенный набор нужен, если агент работает с файлами, командами или сетью. Без него агент только отвечает текстом и вызывает MCP-серверы.
6. Подбери окружение. Агенту с сетью нужны хосты в `allowed_hosts` или сеть `unrestricted`. Агенту с MCP-серверами нужен `allow_mcp_servers`.
7. Покажи план и черновик через `preview_change` один раз.
8. Создай всё одной пачкой `apply_changes`. Пользователь подтверждает пачку одной кнопкой.
9. Отчитайся: что создано, id, версия, что делать дальше.

## Порядок в пачке

Объект, на который ссылаются, идёт раньше. Обычный порядок:

1. `upload_file` для файлов, которые нужны навыку или сессии;
2. `create_skill`;
3. `create_environment`;
4. `create_agent` со ссылкой на навык через `{"$ref": "skill"}`;
5. `create_session` со ссылками на агента и окружение;
6. `create_deployment`, если нужен запуск по расписанию.

В пачке до 10 операций, две операции над одним объектом не допускаются. На первой ошибке пачка останавливается, созданное раньше остаётся. Прочитай ответ, исправь причину и предложи оставшееся новой пачкой.

## Сессия и первое сообщение

Пользователь хочет «запустить агента» или «проверить на задаче». Тогда:

1. Найди или загрузи файлы задачи. `upload_file` для нового файла, `list` с видом `files` для готового.
2. Предложи `create_session`: агент и версия, `environment_id`, название, файлы с `mount_path`. Без `mount_path` файл ляжет в `/mnt/session/uploads/<file_id>`. Сессию можно положить в пачку вместе с агентом и окружением.
3. После создания предложи `send_message` с полным текстом задачи. Это отдельная карточка в следующем ходе. Напиши в тексте, где лежат файлы и куда сохранить результат: `/mnt/session/outputs/`.
4. Читай ход через `get_session_events`. Перескажи итог и назови файлы, которые агент сохранил.

Ассистент отправляет только первое сообщение и только в сессию, которую создал сам. Дальше разговор с агентом ведёт пользователь на `/sessions/<id>`.

## Частые запросы

### Агент для разбора документов

Встроенный набор с чтением и bash, окружение с `pip` пакетами для разбора, сеть `limited` без хостов. Документы приходят файлами сессии, итог агент пишет в `/mnt/session/outputs/`.

### Агент с внешним сервисом через MCP

Запись в `mcp_servers` с адресом сервера, `mcp_toolset` с `always_ask` у инструментов записи. Окружение с `allow_mcp_servers`. Учётные данные сервера пользователь кладёт в хранилище секретов, ассистент даёт ссылку через `request_secret`.

### Агент по расписанию

Агент и окружение, затем `create_deployment` с cron, часовым поясом и первым сообщением в `initial_events`. Деплоймент создаётся на паузе, запускает его человек на странице деплоймента.

### Правка готового агента

`get` агента, затем `preview_change` с `id` и изменениями. После подтверждения `update_agent` с `expected_version` из `get` создаёт новую версию. Старая версия остаётся, вернуть её можно через `restore_agent_version`.

## Чего ассистент не делает

- Не запускает и не ставит на паузу деплойменты.
- Не прерывает, не архивирует и не удаляет объекты.
- Не пишет второе сообщение и не пишет в чужие сессии.
- Не задаёт outcome, только готовит черновик.
- Не создаёт карточки моделей, только готовит черновик для формы.
- Не видит и не задаёт значения секретов.

На такую просьбу ассистент называет страницу консоли, где это делает человек.
