# Как написать навык

Изменения: правила пересказаны по навыку `skill-creator` из anthropics/skills (Apache-2.0) и спецификации Agent Skills с agentskills.io. Мы убрали прогон оценок через `claude -p` и запуск скриптов в песочнице ассистента: ассистент пишет пользователю, как проверить навык в тестовой сессии. Источники в `THIRD_PARTY_NOTICES.md`.

## Устройство навыка

Навык это папка:

```
my-skill/
  SKILL.md          обязательный файл
  scripts/          скрипты, которые агент запускает
  references/       справка, которую агент читает по мере надобности
  assets/           шаблоны и файлы для результата
```

Платформа кладёт папку в песочницу агента. Агент всегда видит имя и описание навыка, тело `SKILL.md` читает, когда задача подходит, а файлы из `references/` открывает по ссылке из тела.

## Frontmatter

`SKILL.md` начинается с блока YAML:

```
---
name: pdf-report
description: Собирает отчёт PDF из таблицы CSV. Используй, когда пользователь просит отчёт, сводку или PDF по данным из таблицы.
---
```

- `name` до 64 знаков: строчные латинские буквы, цифры и дефис. Имя совпадает с именем папки.
- `description` до 1024 знаков. Первая часть говорит, что делает навык. Вторая говорит, когда его брать: слова и ситуации, по которым агент поймёт, что навык нужен.
- Агент решает, открыть ли навык, только по описанию. Всё условие вызова пишите в описание, а не в тело.
- Описание чуть настойчивее, чем кажется нужным. Агенты чаще не открывают навык, чем открывают лишний раз.

## Тело SKILL.md

- Короче 500 строк. Если больше, вынесите части в `references/` и в теле напишите, когда какой файл читать.
- Пишите в повелительном наклонении: «Прочитай таблицу», «Сохрани отчёт в `/mnt/session/outputs/`».
- Объясняйте, зачем правило. Агент лучше следует правилу, когда понимает причину.
- Покажите формат результата образцом.
- У справки длиннее 300 строк в начале оглавление.
- Если навык работает с несколькими вариантами (разные форматы, разные сервисы), положите каждый вариант в свой файл `references/` и в теле скажите, как выбрать.

## Скрипты

Скрипт нужен там, где агент иначе каждый раз пишет одно и то же: разбор формата, расчёт, сборка файла.

- Скрипт работает без вопросов к пользователю. Все входные данные идут аргументами.
- `--help` описывает аргументы и пример вызова.
- Ошибка говорит, что не так и как исправить, и даёт код выхода не ноль.
- Вывод структурный: JSON или строки с понятными полями, чтобы агент мог его разобрать.
- Зависимости перечислите в теле `SKILL.md`. Пакеты для них ставит окружение агента (`pip`, `npm`, `apt`).

## Безопасность

Навык не содержит вредоносного кода и не делает того, чего не обещает описание. Навык, который просит агента отправить данные наружу или скрыть действия от пользователя, ассистент не пишет.

## Как проверить навык

Ассистент не запускает скрипты сам. Проверка идёт в тестовой сессии:

1. Подключите навык к агенту, у которого есть встроенный набор с bash.
2. Создайте сессию и отправьте задачу, на которую навык должен сработать. Ассистент может предложить `create_session` и `send_message`.
3. Посмотрите события сессии. Агент открыл `SKILL.md`? Запустил скрипт? Сохранил результат в `/mnt/session/outputs/`?
4. Отправьте задачу, на которую навык срабатывать не должен, и проверьте, что агент его не открыл.
5. Исправьте описание или тело и создайте новую версию через `create_skill_version`.

## Ограничения платформы

- Все файлы навыка вместе до 1 МБ.
- Создание навыка: `create_skill` с `display_title` и списком файлов `{path, content, encoding}`. Двоичный файл идёт в `base64`.
- Новая версия заменяет весь набор файлов. Пришлите все файлы, а не только изменённые.
